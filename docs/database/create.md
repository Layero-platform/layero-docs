# Как завести базу

:::warning[Раздел в тестировании]

Базы данных и Data API открыты пока не всем: раздел проходит закрытый
пилот на нескольких аккаунтах. Если в меню панели нет пункта
«Базы данных» — доступа у вас ещё нет, и создать базу не получится
ни из панели, ни из CLI.

**Чтобы попасть в пилот**, напишите нам в чат «💬» в правом нижнем
углу [панели](https://app.layero.ru) — включим вручную. Другого способа
получить доступ сейчас нет.

:::

## Из панели

1. Откройте [app.layero.ru](https://app.layero.ru) и выберите организацию.
2. В меню слева — **Базы данных**. Нет такого пункта — доступа пока нет,
   см. выше.
3. Нажмите **Создать базу**. Откроется окно, а не отдельная страница:
   заканчивается оно там же, где началось, и список под ним уже показывает
   новую базу.
4. Выберите размещение — [общая база или своя
   конфигурация](#какую-базу-выбрать).
5. Задайте имя. Латинский слаг подставится сам, его можно поправить: слаг
   попадёт в адрес базы и потом не меняется, даже если переименовать базу.
6. При желании отметьте [расширения](#расширения). Не отметили — ничего
   не потеряли, включаются они и позже.
7. **Создать**.

Общая база готова примерно за двадцать секунд. База со своей конфигурацией
поднимается **7–13 минут**: карточка в списке показывает шаг подготовки и сама
обновляется, F5 нажимать не нужно.

:::note[Письма не будет]

Мы не отправляем уведомление о готовности — ни на почту, ни в Telegram.
Держите вкладку открытой или зайдите позже: карточка покажет состояние.

:::

## Из CLI

```bash
layero db create moya-baza
```

Команда ждёт готовности и печатает строку подключения **один раз** — второй
раз её не покажет никто, пароль можно только сменить. Сохраните её сразу.

Организация берётся из текущего каталога, если он связан с проектом
(`layero link`). Иначе укажите явно:

```bash
layero db create moya-baza --org moya-organizaciya
```

Из CLI заводится только **общая** база: флагов конфигурации, версии
и диска у команды нет. База со своей конфигурацией заказывается пока
только из панели.

Посмотреть, что получилось:

```bash
layero db list
```

## Какую базу выбрать

**Общая база** живёт на общем сервере Layero рядом с приложением. Размер
и число подключений заданы тарифом, выбирать нечего — это и есть её смысл:
нажали и работаете. Одна такая база входит в тариф Pro, и за неё ничего
не списывается.

**База со своей конфигурацией** — отдельный сервер только под вас: ядра,
память и диск выбираете вы. Она тарифицируется отдельно, цену мастер
показывает до нажатия «Создать», и та же сумма потом стоит в карточке базы.
Регион — Москва.

:::note[Вторая общая база не заводится]

На попытку завести вторую общую базу сервер отвечает: «база с Shared CPU
у организации уже есть. Следующую заведите выделенным инстансом». Это
не ошибка и не временное ограничение: объём общего сервера конечен,
и продаётся он по одной базе на организацию.

:::

## Расширения

При создании можно сразу включить `pgcrypto`, `uuid-ossp`, `citext`,
`pg_trgm`, `unaccent` и `pgvector`. Это не обязательный шаг: тот же список
лежит в разделе **Расширения** у готовой базы, и включить их можно
в любой момент.

Список приходит с сервера, а не зашит в панели: если расширения нет
в списке — его нет и на сервере, и просить включить его командой
бесполезно.

## Что дальше

- **Подключить к проекту.** Тогда строка подключения приедет в сборку сама,
  в переменной `LAYERO_DATABASE_URL` — вписывать её руками не нужно.
  Из CLI: `layero db connect moya-baza` из каталога проекта. Отвязать
  можно в панели, на странице базы, вкладка «Проекты».
- **Подключиться самому** — [строка подключения, режимы TLS
  и рецепты для драйверов](./connect.md).
- **Открыть базу по HTTP** без своего сервера — [Data API](../data-api/index.md).

## Если не получилось

| Что отвечает платформа | Что это значит |
|---|---|
| `not found` на создание, раздела нет в меню | Организация не в пилоте. Напишите нам в чат панели |
| «база с Shared CPU у организации уже есть» | Общая база уже заведена. Следующая — со своей конфигурацией |
| Кнопка «Создать базу» с бейджем **Pro** | Нужен тариф Pro: на бесплатном базы не заводятся |
| Подготовка идёт дольше 20 минут | Напишите нам: карточка застряла, сама она не починится |

Отказы приходят с человеческим текстом — перескажите его нам целиком, если
непонятно, что делать.
