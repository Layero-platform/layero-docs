# Навыки для AI-агентов

Инструкции, которые агент (Claude Code, Cursor) подхватывает, когда человек
просит настроить деплой на Layero. Лежат здесь, потому что описывают тот же
публичный контракт, что и страницы в `docs/`, — и обязаны меняться вместе
с ними.

🚨 Docusaurus этот каталог НЕ рендерит: он читает только `docs/` и `i18n/`.
Файлы отсюда распространяются отдельно.

| навык | о чём |
|---|---|
| `layero-json` | конфигурация сборки файлом в репозитории |

## Правило

Навык обязан совпадать со страницей документации по фактам. Расходиться им
нельзя: агент напишет файл по навыку, а человек будет сверять со страницей.
Правя одно — правьте второе.
